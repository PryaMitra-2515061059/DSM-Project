Kopi Batin - Modul Data Pelanggan

File dipisah dari modul_data_pelanggan_kopi_batin.html tanpa mengubah fitur.

Cara menjalankan:
1. Pastikan index.html, style.css, dan script.js berada dalam folder yang sama.
2. Buka index.html di browser.
3. Saat ini autentikasi dan data masih menggunakan localStorage seperti file asli.
4. Tahap berikutnya dapat disambungkan ke Supabase.
